# Orrery v2.1.0 Release

This release package contains:

- BLP Orrery v2.1.0 portable desktop viewer
- WindowsShellExtension Orrery v1.2.0 thumbnail provider package

## Highlights

- Added Neverwinter Nights `.plt` preview support.
- Added `.plt` Explorer thumbnail registration for the shell extension.
- Kept support for BLP, DDS, BioWare/NWN compact DDS, TGA, ICO, PNG, and JPG/JPEG previews.
- Includes the About-window changelog and version metadata updates.
